## Required Wording

Use this wording in future docs and demos:

> real public railway platform footage with a CCTV-like elevated/static angle

Do not call this clip actual CCTV. Do not call it Indian Railway-specific. It is useful
for local demo/testing and body-vs-head comparison, but production validation still
requires approved real Indian Railway CCTV or a formally released railway/metro CCTV
dataset.
